# R521 해외 원배당 흐름으로 수정

- 정밀분석에서 국내 변동표·카드 변동문구·상단 국내 변동 요약을 제거. 국내 현재 구매배당은 유지하되 해외 흐름을 대신하지 않는다.
- 실제 수집한 업체별 가격과 원천 시각을 이력에 저장. 피나클 동일 업체의 이력이 2개 이상이면 우선 표시한다. 이전에 저장하지 않은 피나클 과거 가격은 만들지 않는다.
- 피나클 이력이 부족하면 최근 연속된 동일 업체 구성의 해외 중앙값만 사용하고 출처를 구별한다. 국내 이력, 한 번뿐인 해외 관측, 변경된 업체 구성으로 흐름을 만들지 않는다.
- 변동표 최대 5행. 데이터 분석은 직전 변동→최근 가격의 상승·하락·유지와 변화율, KST 원천 시각을 최대 5문단으로 표시한다. 같은 가격의 연속 수신은 변동 행을 늘리지 않는다.

## 검증과 한계

- 수정 전 국내흐름 노출 회귀검사가 실패하는 것을 확인했다. 수정 후 R519/R521, R518, R474, R520 통과. 실제 업체 가격 저장, 피나클 하락/중앙값 상승의 구분, 직전 기준, 업체 변경·미래 시각 거절, 누락 시 생략, 5행 제한 검증.
- 전체 83개 중 51개 통과, 기존 32개 실패와 동일하며 신규 실패 없음. 네트워크 전용 검사 2개 제외. 기존 실패 목록: r519-flow-integration-validation.md.
- 별도 코드 검토에서 차단 문제 없음. 모의 수집/렌더링 검증을 운영 실시간 수신 확인으로 표현하지 않는다. 운영 화면에서 해외 원자료가 실제 수신되는지 별도 확인이 필요하다.
