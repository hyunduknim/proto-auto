# R462 배당 History

정밀배당분석의 배당 흐름 그래프를 배당 History로 교체했다. 현재 배당과 초기/변경 배당별 동일배당 전적, 결과 막대, 조회 순서 결과, 과거 경기 목록을 제공한다.

## 자료와 계산

- 젠토토 공개 경기표에서 회차·번호·팀·일시를 확인하고 공개 유사배당 상세표를 조회한다.
- 유사배당 집계 수치를 재사용하지 않고 모든 선택지 가격이 소수 둘째 자리까지 일치하는 기록만 집계한다.
- 시장 종류·현재 기준값·최신 가격을 검사한다. 변경 단계 메타데이터가 있으면 선택 단계와 경기 식별자도 검사한다.
- 출처의 결과 강조를 사용한다. 일반 승패에서 강조 없는 동점 점수는 무승부, 그 외 미확인은 별도 표시한다.
- 동일 표시 중복을 제외한다. 개별 경기 날짜와 과거 기준값이 없으므로 기록 건수이며 완전히 식별된 경기 수가 아니다. 해당 한계를 화면에 공개한다.
- 원자료의 표시 순서를 유지한다. 연도 외 날짜를 만들거나 실제 시간 순서로 표현하지 않는다. 목록은 최대 100건, 집계는 전체 일치 기록이다.
- 공개 자료가 없는 경우 재시도 안내를 표시한다. 정산·픽·저장 상태를 수정하지 않는 별도 GET 경로이며 조회 캐시와 동시 요청 제한을 둔다.

## 배포 전환 호환 보강

운영에서 새 화면과 이전 버전 Durable Object가 동시에 응답하는 구간을 확인했다. History는 edge에서 기존 `/api/state` 공개 조회를 통해 경기 정보를 읽고 처리하도록 분리했다. 상태 조회 실패/잘못된 형식에서는 503으로 중단하며 edge KV 읽기나 상태 초기화로 대체하지 않는다. 경기별 시장 가격·기준값을 그대로 사용한다. 이전 버전 DO를 모사한 테스트(기존 History 경로 404)를 먼저 재현한 후, 새 경로 200 및 상태 오류 503 검사를 통과했다. 기존 `/api/state`의 유지보수 예약은 계속 적용된다.
