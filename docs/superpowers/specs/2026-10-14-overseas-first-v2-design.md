# 해외배당 중심 자동마킹 V2 교체 설계서

작성: 2026-10-14 KST
기준 코드: R505 / 891fd7c1a3e6ac8065316e85ee92b58db2ae043e
상태: 설계 검토용. 새 엔진 구현·운영 전환·새 해외 API 연결 완료를 의미하지 않습니다.

## 1. 목적과 교체 범위

국내배당에서 여러 내부 점수를 파생하던 기존 추천 엔진을 폐기하고, 시각과 출처가 확인되는 해외 시장배당을 주된 분석 입력으로 사용한다. 국내 프로토번호와 국내 판매배당은 경기 식별 및 최종 가격 비교에 사용한다. 이는 직전 대화에서 제시한 방향을 반영한 운영 가정이다.

성공의 기준은 적중률 상승을 미리 보장하는 것이 아니다. 동일 조건의 가격 비교, 재현 가능한 판단 기록, 빠른 화면 응답, 정확한 정산 및 실증 가능한 성능 평가를 제공하는 것이다.

교체 대상: 기존 자체 4축 가중 확률, 근거 없는 보정 확률, 추천·시장 비율 강제 배정, 과거 특정 경기번호에 의존한 자동 정정, 화면 조회 중 수집·전체 상태 복제, 설정 누락 시 관리자 인증 허용.

보존 대상: 기존 경기와 정산 원본, 당시 픽·배당·등급·회차·관측 시각, 수동 변경 이력, 취소 이력. 이미 시작되거나 정산된 픽은 새 엔진으로 소급 재작성하지 않는다.

배포 형식은 검증한 JS 한 개이며, 사용자 제공물은 그 JS만 들어 있는 ZIP 한 개다. 개발 소스는 수집·정규화·판단·저장·정산·화면을 모듈로 분리한다.

## 2. 선택한 접근과 대안

선택: 새 엔진과 작은 조회 API를 별도로 구성한 뒤, 기존 기록을 읽기 전용으로 이전하고 새 경기부터 전환한다. 기존 제품의 프로토번호·시간순 카드 사용 방식은 유지하되 표시 내용과 데이터 흐름은 새로 구성한다.

기존 엔진에 해외배당 가중치만 덧붙이는 방법은 변경량이 작지만 감사에서 발견한 보호 장치 미연결과 정책 충돌을 남기므로 채택하지 않는다.

기존 저장소와 기록까지 지우고 새로 시작하는 방법은 구현이 단순해 보이지만 과거 픽·정산과 성능 비교 근거를 없애므로 채택하지 않는다.

## 3. 데이터 공급과 실제 연결 확인

1차 해외 공급 어댑터는 The Odds API V4를 대상으로 설계한다. 기존 wrangler.jsonc에는 THE_ODDS_API_KEY 요구 항목이 있지만 R505에는 이 API의 실제 조회 코드가 없다. 키 존재·유효성·남은 사용량·현재 구독 범위는 아직 확인되지 않았다. 비밀값은 서버에서만 읽고 화면·로그·문서로 출력하지 않는다.

기존 연결 자격증명을 사용해 구현 단계에서 스포츠 목록과 사용량을 확인한다. 이 확인 전에는 KBO·NPB·KBL·배구 또는 특정 해외 업체가 지원된다고 표시하지 않는다. 필요한 해외 라인이나 리그가 없으면 해당 경기는 보존하고 해외 비교 불가로 표시한다. 임의 확률로 채우지 않는다.

Pinnacle 등 특정 업체는 실제 응답에 있을 때만 표시한다. 특정 업체를 반드시 받을 수 있다고 약속하거나 사이트 표시값을 지연 없는 거래 가능 가격으로 취급하지 않는다.

과거 배당 API는 유료 사용 조건이므로 자동 결제·신규 구독을 진행하지 않는다. 과거 자료가 없으면 시작일부터 관측 기록을 누적한다. 첫 수집 배당을 실제 최초 개장배당으로 부르지 않는다.

수집은 스포츠·리그·시장별 실제 지원 목록으로 제한하고, API 잔여량을 읽어 일일 사용 예산과 조회 간격을 지킨다. 기본 간격은 지원 범위와 현재 사용량을 확인한 뒤 설정한다. 401·403·429·잔여량 소진은 서로 다른 상태로 표시하고 지수 재시도로 제한한다. 무한 재시도하지 않는다.

국내배당은 별도 어댑터가 담당하며 분석 확률을 생성하지 않는다. 원천과 관측 시각이 검증되지 않으면 가격 비교 후보를 만들지 않는다.

## 4. 경기와 시장의 일치 규칙

경기 키는 공급자 이벤트 ID, 종목, 리그, 홈·원정 팀, UTC 시작 시각을 포함한다. 국내 프로토번호와 해외 이벤트 ID의 대응표를 저장한다. 표기 차이는 검토된 별칭표만 사용한다. 홈·원정 뒤집힘, 더블헤더, 리그 불일치 또는 복수 후보는 자동 연결하지 않는다.

시작 시각 차이는 최대 5분까지 검토 후보로 허용하되, 다른 식별자가 모두 일치해야 확정한다. 시간 변경은 이력으로 남긴다.

시장 키는 전체/전반/이닝 등 구간, 정규시간/연장 포함 규칙, 승패/3결과 승무패, 핸디캡 종류, 기준점, 푸시·취소 정산 규칙을 포함한다.

유럽식 3결과 핸디캡과 아시안 2결과 핸디캡은 비교하지 않는다. 축구 정규시간 승무패와 연장 포함 승패를 비교하지 않는다. 언더 2.5와 언더 3.0을 동일한 상품으로 계산하지 않는다. 정수 라인의 푸시 규칙이 불명확하면 비교를 보류한다.

기존 최소 국내배당 1.31, KBO 핸디캡 절댓값 2.5 조건은 유지한다. 해외에서 같은 2.5 라인이 없으면 일반적인 1.5 라인으로 대체 추정하지 않는다. 해외 라인으로 국내 라인을 보간하는 모형은 1차 범위에 포함하지 않는다.

## 5. 해외 시장 기준 계산

각 업체의 동일 시장 전체 결과 집합이 완전하고 유효할 때만 마진을 계산한다. 2결과와 3결과를 분리한다. 가격은 유한한 숫자이며 1보다 커야 한다.

각 업체별 역배당을 합으로 정규화하는 비례 방식으로 마진 제거 기준값을 계산한다. 이 방법이 참 승률을 보장하지 않는다는 점을 화면과 판단 기록에 명시한다. 업체별 값의 중앙값을 구하고 결과 합이 1이 되도록 정규화해 해외 시장 기준값을 구성한다.

동일 운영 브랜드의 중복 피드는 한 표로 처리한다. 여러 업체를 서로 독립적인 전문가나 독립 자료원 수로 표시하지 않는다.

시장별 providerUpdatedAt과 receivedAt을 따로 저장한다. 출처 시각이 없으면 신선도 확인 불가, 서버 시각보다 10초 이상 미래면 잘못된 시각으로 처리한다. 초기 비교 유효기간은 경기 전 180초다. 이보다 오래된 값은 마지막 관측값으로만 보여 주고 새 비교 신호에 사용하지 않는다. 공급자 업데이트 주기와 관측 실험에 따라 이 기준은 버전 관리해 조정할 수 있다.

국내배당 × 해외 시장 기준값 - 1은 시장 기준 가격 차이로 표시한다. 검증된 모델 기대수익 또는 실제 승률이라고 부르지 않는다. 업체별 분산, 관측 시각 차이, 기준점 일치 여부를 함께 남긴다.

새 입력이 없으면 국내배당이나 옛 자체 모델로 해외 값을 만들어내지 않는다.

## 6. 추천과 자동마킹

가장추천 15%·추천 25%와 시장 20/20/60의 강제 배정을 제거한다. 추천이 적거나 0개여도 비율을 채우지 않는다. 조합은 생성하지 않는다.

1차 가동은 검증된 해외 비교 신호와 관찰 후보를 생성하는 단계다. 기존 일반·추천·가장추천 이름은 UI 호환을 위해 남길 수 있지만, 검증 전 후보를 추천·가장추천으로 승격하지 않는다. 기존 과거 등급은 당시 기록으로 보존한다.

가격 차이가 양수라는 이유만으로 좋은 픽으로 확정하지 않는다. 일치한 업체 최소 3곳, 동일 시장·라인·규칙, 유효 시각, 국내 판매 가능 여부를 만족한 경우만 비교 후보로 기록한다. 이는 데이터 품질 조건이며 예측 성능 증명이 아니다. 업체가 부족한 경기는 화면에 남기되 후보를 만들지 않는다.

추천 승격은 구현 뒤 별도 사전 등록한 검증 표본에서 평가한다. 최소 100개 중복 제거 경기의 완전한 사전 기록은 검토 시작 조건일 뿐 충분한 검증이나 추천 허가 조건이 아니다. 종목·시장별 성과와 수익률의 불확실성을 확인하지 못하면 승격하지 않는다.

선발·라인업·부상 정보는 실제 수집하고 시각을 확인한 자료만 보조 표시한다. 없는 정보를 자체 AI 분석으로 대체하지 않는다. 데이터 미연결, 노후 배당, 미지원 시장은 각각 구분해 짧게 표시한다.

## 7. 정산과 기록

배당 수집과 점수 수집은 별도 상태·실패·재시도 흐름을 갖는다. 경기 시작 후 일정 시간이 지났다는 이유만으로 종료 또는 결과를 추정하지 않는다.

전체 종료 상태와 점수, 동일 경기 식별자, 해당 시장의 구간·연장·푸시 규칙이 확인된 경우에만 정산한다. 지원되지 않는 점수 소스나 구간은 검토 대기로 남긴다. 배당 API의 점수 엔드포인트가 모든 리그·구간을 제공한다고 가정하지 않는다.

결과 정정은 원본 결과를 덮어쓰지 않고 정정 이벤트와 근거를 추가한다. 특정 경기번호와 고정 점수를 본문에 박아 넣지 않는다.

연기·취소는 검증된 상태와 판매 규칙을 확인해 적특 처리한다. 정수 기준점의 동점·반환 등 별도 규칙이 필요한 경우에는 임의 적중·낙첨·적특으로 결정하지 않고 공식 시장 결과를 확인한다.

시작된 경기의 픽과 마킹 배당은 고정한다. 수동 변경과 정산은 같은 직렬 쓰기 경로와 트랜잭션을 이용한다. 재전송·재실행은 같은 이벤트 ID로 중복 반영되지 않아야 한다.

## 8. 저장·보안·화면

현재 Durable Object의 기존 키는 삭제하지 않는다. SQLite 테이블 또는 작은 레코드 단위 저장을 사용하고, schemaVersion 및 이전 체크섬을 둔다. 기존 전체 상태는 한 번 백업하고 기존 픽·정산을 읽기 전용 이력으로 가져온다. 이전 전후 회차별 건수와 픽·배당·결과 체크섬이 일치해야 한다.

화면 조회는 캐시된 작은 스냅샷만 반환한다. 외부 API, 정산, 과거 정정, 전체 모델 계산, 알람 예약 완료를 기다리지 않는다. 상세 기록과 원시 데이터는 필요할 때 별도 조회한다. 상태 갱신에는 현재 시간과 다음 경기 시작 경계가 반영되며 데이터 변경이 없다는 이유로 시작 상태를 고정하지 않는다.

100경기 목록의 초기 JSON은 비압축 250KB 이하를 목표로 한다. 같은 테스트 환경에서 준비된 조회 응답 p95 500ms 이하, 카드 표시 2초 이하를 수용 기준으로 검증한다. 사용자 통신망의 응답 시간을 보장한다는 뜻은 아니다. 실제 관측 성능을 배포 완료 보고에 포함한다.

전체 상태의 반복 복제와 수집원마다 전체 저장하는 구조를 제거한다. 수집은 제한된 동시성으로 원시 응답을 분리 처리하고 검증한 작은 변경 묶음만 커밋한다.

모든 변경 API는 관리자 토큰이 없으면 차단한다. 토큰 미설정은 503, 인증 실패는 401로 구분한다. 키·토큰은 공개 API·URL·에러 로그·내보내기에 포함하지 않는다. 저장 실패를 성공으로 반환하지 않으며 메모리와 영구 저장의 상태를 분리해 표시한다.

화면은 모바일 카드형, 날짜→시간→프로토번호 오름차순이다. 해외 기준배당, 국내배당, 동일 기준점, 최초 관측 대비 현재 변화, 수집 시각, 비교 가능 여부, 짧은 판단 사유를 우선 표시한다.

## 9. 성과 검증과 전환 기준

모든 판단을 경기 전에 고정 기록한다. 신호를 만들지 않은 경기와 그 사유도 기록한다. 실제 결과를 본 뒤 과거 픽이나 확률을 복원하지 않는다.

종목·리그·시장·배당구간별로 표본수, 적중률, 동일 금액 기준 ROI, 국내 가격과 해외 시장 기준의 차이, 마감 직전 동일 시장 가격 대비 차이를 평가한다. 푸시·취소·보류를 분리하고 표본이 작으면 불확실성을 표시한다.

확률 정확도 점수는 확률의 의미와 완전한 결과 벡터가 확보된 경우에만 산출한다. 시장 기준값을 독립 예측 확률로 포장하지 않는다.

필수 재현 검사: 누락·미래 시각, 다른 라인·구간·홈원정·더블헤더, 불완전 결과 집합, 중복 브랜드, 공급 중단·429·사용량 소진, 정규시간과 연장, 푸시, 저장 실패, 동시 수동 변경, 중복 정산, 회차 전환, 시작 경계 캐시, 관리자 토큰 누락, 새 출처 부재 시 추천 0개, 기존 기록 불변.

운영 전환 조건: 실제 해외 조회 성공과 지원 목록 확인, 신규 핵심 검사 전부 통과, 이전 전후 기록 일치, 제한된 관측 가동, 성능 측정, JS 원본·업로드본·ZIP 내부 파일의 해시 일치. 이 조건을 충족하기 전에는 운영 전환 완료라고 보고하지 않는다.

## 10. 단계와 현재 상태

A. 이 설계서 검토: 해외 분석 중심·국내 최종 가격 비교·비율 강제 폐지·기록 보존 범위 확인.
B. 승인된 설계에 대한 구현 계획과 검증 항목 작성.
C. 새 엔진 구현, 공급자 연결 확인, 가상 오류 및 실제 읽기 검증.
D. 읽기 전용 기록 이전과 새 경기 관측 가동.
E. 수용 기준을 확인한 뒤 운영 전환 및 JS 한 개가 들어 있는 ZIP 제공.

현재 완료된 것은 기존 코드 검토와 이 설계서다. API 키 유효성, 실제 해외 데이터 수신, 새 엔진 구현, 새 배포는 아직 완료되지 않았다.
