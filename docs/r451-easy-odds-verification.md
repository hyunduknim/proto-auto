# R451 쉬운 배당 분석과 흐름 차트

사용자 요구: 어려운 용어 없이 어느 방향을 배당이 더 높게 보는지, 쉬운 이유와 차트로 설명. 배당 흐름도 함께 표시.

- 현재 마킹 → 배당으로 본 방향 → 선택지별 막대 → 배당 흐름 선 → 이유 최대 3줄.
- 배당 비교값을 실제 예측 승률로 표시하지 않음. 지난 경기 결과와 배당 비율은 별도 이름과 차트로 구분.
- 현재 마킹과 배당 1순위가 다르면 차이를 명시. 저장 마킹을 바꾸거나 억지로 선택 방향을 지지하지 않음.
- 과거 결과/배당 변화 펼치기에도 손익분기, EV, 환급률, 마진, 시장비중, Wilson, 표본 등 어려운 말 표시 안 함.
- 선 차트는 저장된 시각·선택지 가격과 마지막 실제 관측가격만 사용. 기록이 2개 미만이면 이전 기록 없음 표시. 원천 개장배당과 최초 관측을 섞어 임의로 차트를 만들지 않음.
- INDEX 외 코드의 동일성을 확인: 자동마킹, 등급, 수동픽, 자동정산, 데이터조회 변경 없음(앱 버전·빌드 문자열 제외).

검증: R451 막대 수치(1.49/2.15→59.1%/40.9%), 쉬운 표현, 서로 다른 마킹 설명, 과거 306/565=54.2%, 실제 3시점 하락 선 및 기록 없는 경우, 상태 불변 검사 통과. R450 현재 32경기/모든 시장 렌더 모의검사와 기존 메뉴·JSON·정산우선·근거/잠금 검사 통과.

전체 검사 44개 중 27개 통과, 17개는 수정 전에도 실패하던 기존 검사. 새 실패 없음. 기존 R450 화면 테스트는 새 쉬운 말/차트 요구에 맞게 갱신했고 정산 검사는 유지.
